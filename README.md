# SDcodeeditor 🧠💻

**A powerful, lightweight, and mobile-friendly code editor—accessible anytime, anywhere.**

SDcodeeditor is a versatile, browser-based code editor designed to offer a seamless coding experience across devices. Whether you're tweaking a small script or editing mid-scale projects on the go, SDcodeeditor keeps your workflow smooth and responsive.

## ✨ Features

- 📱 **Mobile-Friendly UI**  
  Enjoy a sleek, responsive interface built with modern web technologies to support a fully functional editing experience on smartphones and tablets.

- 🧾 **Edit Mid-Scale Codebases**  
  Handles medium-sized files and projects with ease. Perfect for tweaking, testing, or working on code without needing a full-fledged IDE.

- ⚡ **Progressive Web App (PWA)**  
  Install it directly from your browser! Works offline once installed, and opens like a native app on your device.

- 🌈 **Syntax Highlighting & Themes**  
  Support for multiple programming languages with customizable themes for comfortable coding.

- 💾 **Auto-Save and Persistent Sessions**  
  Never lose your progress with intelligent auto-saving and session persistence between visits.

- 🚀 **Fast Loading & Minimal Dependencies**  
  Optimized for speed with minimal external bloat—because performance matters.

## 📦 Installation

You can use it instantly at the GitHub Pages site or clone it locally:

```bash
git clone https://github.com/ASriDatta/SDcodeeditor.git
cd SDcodeeditor
open index.html  # Or serve with a local web server
```

To install it as a PWA, open the editor in a browser like Chrome or Edge and choose "Install App" from the address bar.
